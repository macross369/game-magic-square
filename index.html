💡 什麼是魔方陣？

把連續整數 1 到 n² 不重複地排成 n × n 的正方形，使每一列、每一行及兩條主對角線的總和都相同（此總和稱為「魔術常數 M」）。

📜 魔術常數公式與 1×1 ～ 7×7 總整理

魔術常數計算公式（n 為正方形的邊長階數）
M = n ( n² + 1 ) ÷ 2

原理：1 到 n² 的總和為 n²(n²+1)÷2，平均分配給 n 列（或 n 行），每條線的和即為 M！

🚫 2×2 魔方陣為什麼「無解」？

1. 套用公式算出 2×2 的魔術常數：M = 2×(4+1)÷2 = 5。

2. 使用 1、2、3、4 湊出總和為 5，只有 1＋4＝5 與 2＋3＝5 兩種組合。

3. 每個格子都要同時滿足「橫列、直行、對角線」三條線總和為 5，必然會出現重複數字，因此無解！
